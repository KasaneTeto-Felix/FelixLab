Kebijakan Privasi

Terakhir diperbarui: 8 November 2026 · berlaku untuk web Felix Lab Community

1. Siapa kami

Web ini adalah komunitas fans yang dijalankan sendiri oleh Felix Lab (pemilik & pengelola) sebagai tempat nongkrong subscriber YouTube @felixlabofc. Web ini bukan perusahaan, tidak menjalankan iklan, dan tidak melakukan aktivitas bisnis berbayar terhadap datamu.

2. Ringkasan singkat (no drama)

  • Kami tidak menjual, tidak menyewakan, tidak membagikan datamu ke pihak ketiga untuk kepentingan siapa pun.
  • Tidak ada iklan, tidak ada pelacak pihak ketiga, tidak ada profil iklan yang dibangun dari aktivitasmu.
  • Data yang ada hanyalah data yang kamu isi sendiri saat pakai web ini.

3. Data yang tersimpan saat kamu pakai web ini

  • Akun: email (untuk verifikasi & login), username, nama tampilan, dan avatar.
  • Kontenmu: postingan di community, komentar, like yang kamu berikan, lampiran file yang kamu pilih, dan gambar yang kamu tautkan.
  • File upload: foto profil (maks 2 MB), lampiran komentar (maks 20 MB), dan file resource di-upload admin (maks 50 MB) — disimpan pada storage Supabase.
  • Metadata teknis: waktu membuat konten, dan relasi antar data (mis. siapa me-like apa) — semuanya berada dalam database Supabase milik web ini.

Kami tidak meminta data sensitif seperti NIK/KTP, data keuangan, lokasi GPS, atau kontak kamarmu. Tolong jangan menuliskan data semacam itu di kontenmu.

4. Cookie & penyimpanan lokal

Web ini memakai cookie & local storage fungsional saja (bukan pelacak):

  • fx_theme — cookie fungsional: menyimpan pilihan temamu (terang/gelap/ikut HP) supaya nggak balik ke default tiap buka (365 hari). Aktif begitu kamu sendiri memilih tema — sama seperti YouTube mengingat preferensimu.
  • fx_consent — catatan jawabanmu di banner cookie: diterima atau ditolak (365 hari). Cookie wajib, supaya kami tidak menanyakan hal itu berulang-ulang.
  • fx_banner — tanda banner cookie sudah pernah tersaji di perangkatmu, supaya tidak muncul terus-menerus setiap reload (cookie wajib).
  • sb-* — kredensial sesi login milik Supabase Auth, supaya kamu tidak perlu login ulang setiap membuka web.

Kontrolmu tetap penuh: di Setelan (ikon ⚙️) kamu bisa mengubah jawaban banner (terima/tolak) kapan saja, atau Hapus preferensi perangkat ini yang menghapus semuanya seketika — termasuk tema.

5. Layanan pihak ketiga yang dipakai

  • Supabase — menyimpan database (akun, konten) dan file storage. Kebijakan: supabase.com/privacy.
  • Google — hanya bila kamu memilih login "Lanjut dengan Google". Google menangani prosesnya sesuai ketentuan Google sendiri.
  • DiceBear — penyedia gambar avatar default (server mereka melihat permintaan gambar saja, tanpa data personalmu).
  • Google Fonts & Font Awesome (CDN) — sumber font/ikon tampilan.

Praktik data dari layanan tersebut diatur oleh kebijakan privasinya masing-masing; web ini tidak mengirim data tambahan ke mereka di luar yang technically diperlukan.

6. Login dengan Google

Kalau kamu memilih "Lanjut dengan Google", Google hanya mengirim ke web ini Nama, email, dan avatar profil dasar dari akun Google-mu. Tidak ada perizinan membaca email, kalender, atau apa pun lain. Tidak ingin pakai Google? Login dengan email & kata sandi biasa — fitur web sama lengkapnya.

7. Moderasi & centang verified

Konten yang melanggar aturan komunitas (spam, SARA, konten dewasa, doxing, penipuan) dapat dihapus oleh moderator, dan akun pelanggar dapat dicabut centangnya. Moderasi hanya menyentuh konten yang tampil publik — moderator tidak membaca data pribadimu di balik layar.

8. Keamanan data

  • Akses database dilindungi Row Level Security (RLS) — user biasa tidak bisa menyentuh data orang lain; hanya pemilik web yang memegang peran admin.
  • Kata sandamu dipegang oleh Supabase Auth (di-hash, tidak pernah tersimpan dalam bentuk asli di web ini).
  • File yang di-upload hanya bisa dihapus/diganti oleh pemiliknya (avatar, lampiran) atau admin (file resource).

9. Usia minimum

Web ini ditujukan untuk usia 13 tahun ke atas (atau usia minimum yang diwajibkan negaramu). Kalau kamu di bawah itu, izinkan orang tua/walmu dulu sebelum membuat akun — dan tolong jangan share data pribadi di publik.

10. Hak-hakmu atas data

  • Lihat & koreksi — data profilmu bisa kamu lihat & ubah sendiri di menu profil.
  • Hapus konten — kontenmu dapat dihapus dari UI, atau diminta ke admin.
  • Hapus akun & seluruh data — kirim permintaan ke email di bawah; diproses manual oleh pemilik web.
  • Tarik persetujuan cookie — kapan saja lewat Setelan → Tolak cookie / Hapus preferensi.

11. Perubahan kebijakan

Kebijakan ini bisa diperbarui sewaktu-waktu seiring fitur bertambah. Setiap perubahan dicatat di tanggal "Terakhir diperbarui" di atas. Menutup banner cookie tidak memengaruhi hakmu atas data.
